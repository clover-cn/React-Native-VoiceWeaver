# 现场录制参考音频

音频管理提供「上传音频」和「现场录音」两个入口。现场录音仅保存到本机，不调用模型、不自动识别文字。

## 操作

1. 点击「现场录音」，首次使用时授予麦克风权限。授权结束后需要重新长按，不会自动录音。
2. 长按超过300毫秒开始录音；松手结束。向上滑动超过80个逻辑像素后松手取消，松手前移回可恢复。
3. 至少录制1秒，最多20秒，到达上限自动结束；若此时处于上滑取消状态，则丢弃本段。
4. 录制完成后可试听、重录。点击「确认使用」，填写名字、情绪和性别，点击「保存到音色库」。

录音前会暂停应用内听书和试听，结束后不自动恢复播放。关闭面板、退后台或被系统打断会丢弃未确认的录音。

## 实现约定

- Android 使用 AudioRecord，鸿蒙使用 AudioCapturer；目标为48 kHz、单声道、16位 PCM WAV。
- 原生按采集帧数限制1～20秒；界面只轮询元数据，不接收音频二进制。
- 会话标识在启动前生成。取消标记覆盖异步初始化过程，避免松手、退出后才开始录音。
- 临时文件位于应用缓存目录 `reference-recordings`，与正式参考音频分离；取消、重录、关闭、成功入库后释放，下次初始化清理遗留文件。
- 复用现有参考音频导入校验和音色库记录，不新增持久化字段；无数据迁移。保存失败时保留当前前台录音供重试。

## 验证

运行 `npx jest src/ts/modules/NovelReader/__tests__ --runInBand` 验证手势、启动竞争、后台取消及结果边界。

真机需分别验证权限允许/拒绝/永久拒绝、麦克风占用与系统打断、1秒和20秒边界、长按/松手/上滑、试听重录、入库与配音绑定、空间不足和临时文件清理。自动化界面测试与构建不能替代设备采集验证。
